# RaceStudio Mac

An open-source, native macOS motorsport telemetry analysis application inspired by AiM RaceStudio 3 Analysis.

## Goals

- Import AiM XRK/XRZ telemetry files
- Visualize RPM, speed, acceleration, and GPS channels
- Compare laps and analyze time differences
- Display GPS track maps and racing lines
- Analyze gear changes, braking, and corner performance
- Integrate an AI Race Engineer using OpenRouter

## Planned Technology

- Tauri 2
- Rust
- React + TypeScript
- SQLite
- OpenRouter

## Development

Work in progress.
