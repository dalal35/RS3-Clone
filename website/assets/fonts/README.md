# Landing fonts

Self-hosted Latin WOFF2 files preserve the existing landing-page typography and
remove the render-blocking Google Fonts stylesheet. DM Sans and Space Grotesk
contain variable weights; IBM Plex Mono supplies the landing's regular labels.
The corresponding SIL Open Font Licenses are included alongside these files.

- DM Sans: https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K6z9mXg.woff2
